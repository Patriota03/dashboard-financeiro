☁ Sincronização com a nuvem

Os dados ficam num repositório privado do GitHub e são sincronizados automaticamente: ao abrir o app, a cada 30 segundos, ao voltar para a aba e quando a internet reconectar. Cole o token de acesso criado nas configurações do GitHub.

📂 Importar dados

Importe um arquivo .json (backup do app) ou .csv (exportação do botão Exportar). Os lançamentos são adicionados, sem apagar os atuais.
